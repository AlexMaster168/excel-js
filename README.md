# Mini Excel — JavaScript + TypeScript

Мини-табличный процессор в браузере: формулы, графики, несколько листов,
импорт/экспорт `.xlsx`, undo/redo, drag-and-drop объектов. Собран на собственном
мини-фреймворке (без React/Vue) — Vite + строгий TypeScript в ядре.

Изначально — учебный проект курса Владилена Минина «excel-course», доведённый
до полноценного мини-Excel.

## ✨ Возможности

### Таблица

- Сетка ячеек с навигацией клавиатурой (стрелки, Tab, Enter) и редактированием.
- **Выделение мышкой**: протягивание прямоугольника по ячейкам, клик/протягивание
  по заголовкам выделяет целые **строки и столбцы**, автопрокрутка к краю.
- Изменение ширины столбцов и высоты строк перетаскиванием.
- **Добавление / удаление / вставка** строк и столбцов (контекстное меню по правому
  клику) — данные, стили и размеры корректно сдвигаются.
- Редактирование названий строк и столбцов (двойной клик по заголовку).
- Форматирование: выравнивание, жирный, курсив, подчёркивание.
- **Copy / Paste диапазонов** (`Ctrl+C` / `Ctrl+V`) — внутри приложения сохраняются
  формулы и стили, наружу/внутрь работает обмен с настоящим Excel через системный
  буфер (TSV).
- **Undo / Redo** (`Ctrl+Z` / `Ctrl+Y`) для всех изменений документа.

### Формулы

- Движок на рекурсивном спуске: ссылки `A1`, диапазоны `A1:B10`, строки `"..."`.
- Операторы: `+ − * / ^ %`, конкатенация `&`, сравнения `= <> < > <= >=`.
- **60+ функций** по категориям с Excel-подобной панелью (поиск, вкладки, описание,
  синтаксис, кнопка «Вставить»):
  - **Математика**: `SUM`, `PRODUCT`, `ABS`, `SQRT`, `POWER`, `MOD`, `ROUND`,
    `CEILING`, `FLOOR`, `PI`, `SIN/COS/TAN`, `LOG/LN/EXP`, `FACT`, `GCD/LCM`, `SUMPRODUCT`…
  - **Статистика**: `AVERAGE`, `MEDIAN`, `MODE`, `STDEV/STDEVP`, `VAR/VARP`,
    **`CORREL`** (корреляция Пирсона), `GEOMEAN`, `RANK`, `COUNT/COUNTA`…
  - **Логика**: `IF`, `AND`, `OR`, `NOT`, `XOR`, `TRUE`, `FALSE`.
  - **Текст**: `CONCAT`, `LEN`, `UPPER/LOWER`, `TRIM`, `LEFT/RIGHT/MID`, `REPT`,
    `SUBSTITUTE`, `FIND`, `EXACT`, `TEXTJOIN`.
  - **Дата/время**: `TODAY`, `NOW`, `DATE`, `YEAR`, `MONTH`, `DAY`.
- Пересчёт зависимых ячеек, защита от циклов (`#CIRC!`), коды ошибок
  (`#DIV/0!`, `#NAME?`, `#REF!`, `#ERROR!`) вместо `undefined`.

### Объекты на листе

- **Таблицы-объекты**: оформление выделенного диапазона (шапка, «зебра», рамка),
  именование. Перетаскивание за бейдж переносит весь диапазон с данными и стилями.
- **Графики**: собственный рендер на SVG (без внешних библиотек) — **столбцы,
  линия, круговая**. Строятся по выделенному диапазону, перетаскиваются мышкой,
  позиция сохраняется.

### Несколько листов

- Вкладки снизу: переключение, добавление, **переименование** (двойной клик),
  **дублирование** и **удаление** (правый клик).

### Импорт / экспорт

- **Открытие `.xlsx/.xls/.csv`** (SheetJS): все листы становятся вкладками,
  первая строка каждого — заголовками столбцов.
- **Экспорт в `.xlsx`** одним кликом.

### Прочее

- Хранение в `localStorage`, маршрутизация по hash (`#`, `#excel/<id>`),
  дашборд со списком таблиц.

## 🚀 Запуск

Требуется [pnpm](https://pnpm.io/) (проект на нём, см. `packageManager`).

```bash
pnpm install      # установка зависимостей
pnpm dev          # дев-сервер на http://localhost:3000
pnpm build        # production-сборка в dist/
pnpm preview      # предпросмотр собранного
pnpm typecheck    # проверка типов (tsc --noEmit)
pnpm test         # юнит-тесты (Vitest)
pnpm test:watch   # тесты в watch-режиме
```

## 🧱 Архитектура

Своя мини-библиотека вместо фреймворка:

- **`Dom`** — тонкая обёртка над DOM-узлом.
- **`ExcelComponent` / `DomListener`** — базовый компонент с декларативными
  DOM-слушателями.
- **`Emitter`** — pub/sub для общения компонентов (`$emit` / `$on`).
- **`createStore`** — redux-подобный стор; **`StoreSubscriber`** уведомляет
  компоненты только об изменениях нужных им ключей состояния.
- **`Router` / `Page`** — hash-роутинг (дашборд ↔ таблица).
- **`history`** — undo/redo поверх стора (стеки снимков + коалесценция ввода).

Документ хранится как `AppState` с массивом листов `SheetState`
(данные, стили, размеры, заголовки, таблицы-объекты, графики). Все изменения —
через чистый `rootReducer`; геометрические операции (сдвиг/перенос/вставка
диапазонов) вынесены в чистые функции `redux/sheetOps.ts` и покрыты тестами.

### Структура

```
src/
├── core/                 # мини-фреймворк и движки (TypeScript)
│   ├── dom.ts, Emitter.ts, ExcelComponent.ts, DomListener.ts
│   ├── createStore.ts, StoreSubscriber.ts, history.ts
│   ├── routes/           # Router, ActiveRoute
│   ├── formula/          # токенизатор, парсер, evaluator, реестр функций
│   ├── chart/            # SVG-рендер графиков + извлечение данных
│   └── xlsx/             # import.ts / export.ts (SheetJS)
├── redux/                # types, actions, rootReducer, sheetOps, initialState
├── components/           # header, toolbar, formula, table, sheet-tabs, context-menu
├── pages/                # ExcelPage, DashboardPage
├── scss/                 # стили
└── constants.ts
```

## ⚠️ Известные упрощения

- Удаление/вставка/перенос строк и столбцов **не переписывает ссылки** в формулах
  (`A1` не сдвигается автоматически).
- Экспорт в `.xlsx` выгружает **вычисленные значения**, а не формулы.
- При импорте/экспорте первая строка трактуется как заголовки столбцов.
- График **не следует** за таблицей при её переносе (это независимые объекты).
- `IF` вычисляет обе ветки; даты хранятся как строки.
